# 只读版本对比与合同族差异审查

用于两版合同、主从合同、订单与附件、跨合同镜像条款的语义对比。保持诊断类只读权限，不因发现差异直接改文件。

## 一、确定比较基线

1. 记录每份文件的名称、版本、日期、SHA256、来源和签署状态；旧版/新版不得仅凭文件名猜测。
2. 确认比较目的：识别实质变更、核对谈判让步、验证修订执行、审查合同族一致性，还是确认签署文本。
3. 检查修订痕迹和批注。未接受插入、删除文字和批注分别列示，不能把工具默认提取结果当作唯一基线。
4. 列明附件、引用文件和未提供材料；文件集不同本身就是差异。

## 二、先建立条款映射，再看文本 diff

自动 diff 只能发现字符变化，不能证明权利义务不变。按“定义/主题＋条款号＋标题＋上下文”建立映射：

| 映射状态 | 含义 |
|---|---|
| 一对一 | 旧条款与新款可直接比较 |
| 拆分/合并 | 一条变多条或多条变一条，须整体比较 |
| 移动 | 位置改变但内容可能未变，须检查引用和优先级 |
| 新增/删除 | 无对应文本，分析权利义务增减 |
| 无法确认 | 相似度不足，保留人工判断，不强行配对 |

条款移动、重新编号、定义替换可能改变交叉引用、文件优先级和责任上限基数，即使正文句子相同也要记为联动差异。

## 三、差异分类与语义复核

每条差异同时标文本类型和实质影响：

- **文本类型**：新增、删除、替换、移动、拆分、合并、编号/引用变化、附件变化、格式/修订状态变化。
- **实质类别**：主体/授权、定义、标的、金额税率、交付验收、付款、IP/数据、责任、解除、争议、证据、语言体例、无法确定。
- **对我方方向**：有利、不利、中性、双向影响、待确认；不要仅以字数或措辞强弱判断。
- **证据状态**：原文直接证实、跨条款推断、缺材料、待法律核验。

逐项问：

1. 谁新增/丧失了权利、义务、抗辩、期限利益或证据优势？
2. 数字、税率、比例、期限、上限基数是否重算并与相关条款勾稽？
3. 定义、交叉引用、文件优先级和附件版本是否同步？
4. 是否改变了已锁定的商业实质或谈判红线？如有，只报告，不擅自回退或恢复。
5. 新旧条文法律效力是否不同？需引用时按现行正式文本核验，不凭经验定性。

## 四、交付与质量门禁

产出条款对照表和差异清单，重大差异关联 R-ID；不实际修订原件。

交付前：

- 每个旧版条款和附件均有去向，每个新版新增内容均有来源标记；
- 无法映射、未提供文件和未解析内容单独列出；
- 所有实质数字重新计算，不仅比较数字是否改变；
- 重大差异回读新旧上下文，并检查关联文件是否已兜住；
- 报告区分“文本有差异”“法律效果有差异”“商业影响有差异”，不互相替代。
