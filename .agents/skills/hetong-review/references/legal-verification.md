# 中国合同审核的法律核验与结论分层

在提出法律结论、引用条文、评定重大风险或起草强制性兜底条款前阅读本文件。
本文件规定核验方法，不替代审核当时对现行法的检索。

## 一、先确定适用法，再评价条款

1. 先识别合同类型、交易实质、主体性质、履行地、是否涉外、是否消费者或劳动者、是否属于招投标、政府采购、金融、建设工程、房地产、数据等特别监管领域。
2. 特别法优先于一般法；再回到《中华人民共和国民法典》总则编、合同编通则及对应典型合同章节。
3. 核对相关司法解释、行政法规和监管规则。规章原则上不是认定合同无效的直接依据，但仍可能产生监管责任；涉及公序良俗、金融安全、市场秩序或宏观政策时，单独分析效力风险。
4. 涉外合同分别分析准据法选择、中国强制性规定、争议解决地与承认执行，不把中国法默认规则套到全部关系上。
5. 合同名称与交易实质不一致时，按真实权利义务识别法律关系；实质不明先问用户，不用改名或换标题掩盖实质。

## 二、法律命题必须留有核验记录

对每个支撑重大结论或关键条款的法律命题，记录：

| 字段 | 要求 |
|---|---|
| S-ID | 稳定来源编号，供 findings 引用，如 S-001 |
| 法律命题 | 要证明什么，不只写“依据《民法典》” |
| 规范文件 | 全称、制定机关、文号（如有） |
| 条文定位 | 编、章、条、款、项；引用与命题直接相关的部分 |
| 时效状态 | 现行有效、尚未施行、已修正、已废止及施行日期 |
| 官方来源 | 官方页面 URL 与本次核验日期 |
| 适用推理 | 本案事实为什么落入该规则，是否存在例外 |
| 核验状态 | 已核验 / 待核验；待核验不得写成确定结论 |

给每个命题分配稳定 S-ID，法名、条号、时效和官方来源只在台账维护一份口径。摘要、分级修正、
谈判表等后续章节引用 S-ID，不另行复制或改写法律归属，防止把甲法的条号误挂到乙法。

### 来源优先级

1. 国家法律法规数据库、全国人大及其常委会、中国政府网；
2. 最高人民法院、最高人民检察院及司法机关官方公报；
3. 国家税务总局及其他有权监管机关的官方页面；
4. 官方公报、权威法规库用于交叉核对；
5. 律所文章、案例解读、搜索结果摘要只作线索，不能作为条文最终依据。

常用官方入口（仍须在每次审核时检索具体现行文本）：

- 国家法律法规数据库：<https://flk.npc.gov.cn/>
- 中国政府网：<https://www.gov.cn/>
- 最高人民法院：<https://www.court.gov.cn/>
- 国家税务总局：<https://www.chinatax.gov.cn/>

已核对过的基础文本入口示例：

- 《民法典》合同编公开文本：<https://www.cac.gov.cn/2020-06/01/c_15925617772683192.htm>
- 合同编通则司法解释（法释〔2023〕13号）：<https://www.court.gov.cn/fabu/xiangqing/419382.html>
- 《增值税法》公开文本：<https://fgk.chinatax.gov.cn/zcfgk/c100009/c5237365/content.html>；
  [实施条例](https://fgk.chinatax.gov.cn/zcfgk/c100010/c5246349/content.html)。两者自 2026 年 1 月 1 日施行；
  增值税暂行条例同时废止，仍须结合纳税义务发生时点及过渡规定，不只看签约日。
- 涉及第三方回款条件：核对[2025 年款项支付条例](https://www.miit.gov.cn/jgsj/zfs/xzfg/art/2025/art_d9b6cd05f3734869aa34caff247089ff.html)
  及[法释〔2024〕11号](https://www.court.gov.cn/zixun/xiangqing/441281.html)，先核对订约时企业规模；不把批复中的旧条例条号直接改为新条号。
- 涉及破产取回、退款或财产隔离：核对[企业破产法](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_d60b9e67b65240e4a739143cca5b57a6.html)及适用司法解释；
  付款、SN 锁定或账户称为“共管”不当然产生所有权、取回权或优先受偿。修订草案不得作为现行规则。

### 核验纪律

- 读条文所在章节及例外，不凭条号记忆、二手文章或搜索摘要下结论；旧条号、草案和征求意见稿不得冒充现行依据。
- 检查审核日、合同成立日、履行期间和争议发生时的新旧法适用；不能只写“截至目前”。
- 法律制定/修正时间与司法解释制定时间分别核对；旧司法解释的制定依据应按其制定时有效法律理解，不得用后来的法律修正倒推其制定依据。
- 法律检索使用抽象化问题，不把合同全文、当事人名称、身份证号、账户、价格或其他商业秘密送入公开搜索或外部服务。
- 网络不可达或没有查到充分依据时，标明“待法律核验”及已核范围；未检索到公开佐证但仍有一般法理基础的，明确写出判断基础和存疑，不编来源、案号或 URL。
- 以某一法律命题为唯一依据的 S1 阻断结论，必须取得正式文本级支持；无法核验时降低确定性并升级人工复核，不用搜索摘要支撑阻断。
- 权威来源之间或检索结果与原有知识冲突时，记录差异并回到正式文本、效力和时点核对；仍不能排除的标存疑，不任意选择更符合预设结论的一项。
- 案例、指导性材料、地方口径和学理意见与法律、司法解释分层表达，不说成普遍强制规则。
- 税率、征收率、发票和优惠事项按具体应税交易、纳税人身份、纳税义务发生时间及审核日政策核验；不得沿用模板税率。

## 三、严格区分法律后果

审核结论至少区分以下类别，不得把“对我不利”写成“无效”：

| 类别 | 表达方式与审核重点 |
|---|---|
| 不成立 / 未生效 | 分析成立要件、批准、约定生效条件及相应义务条款 |
| 无效风险 | 以法律、行政法规强制性规定及法定无效规则为据，说明具体规范与适用事实 |
| 可撤销风险 | 说明撤销事由、主体、期间与可能后果，不等同当然无效 |
| 效力待定 / 无权代理 | 区分追认、表见代理、代表权限、内部审批与对外效力 |
| 不成为合同内容 | 例如格式条款提示说明义务问题；与条款无效分开 |
| 不得对抗 | 说明对何种第三人或相对人发生何种影响，不扩大为整体无效 |
| 可请求调整 | 如违约金司法调整；不预先保证约定数额一定获支持 |
| 约定不明，法律补缺 | 先找补充协议、相关条款和交易习惯，再分析任意性默认规则 |
| 可执行性 / 证据风险 | 条文可能有效，但履行、举证、送达、保全或执行困难 |
| 行政、税务等监管风险 | 不当然推出民事合同无效，分别评价责任与整改 |
| 纯商业或谈判风险 | 明确说“商业建议”，不伪装成法律强制要求 |

## 四、任意性规则与强制性规则分开

1. 对任意性默认规则，写成“未约定或约定不明时，可能适用……”，并说明当事人能否另行约定。
2. 对强制性规则，检查是否存在排除、限制或变相规避；不得把用户“接受风险”当成合法化方案。
3. 对格式条款同时检查：是否实际协商、公平性、重大利害条款提示说明、是否不合理减免责任或加重对方责任、是否排除主要权利、解释规则和非格式条款优先关系。
4. “双方签字确认”“已阅读无异议”不是当然消除格式条款、免责条款或显失公平风险的万能表述。
5. 免责、责任上限、违约金、定金、赔偿范围、间接损失排除分别分析，不相互替代，也不重复获赔。
6. 我方是格式文本提供方时，对我方有利的拟制验收、单方决定、抵销限制、责任限制等异常条款，同样检查我方的提示说明义务和履行证据；不能只审对方提供的文本。

## 五、重大或专项事项的升级条件

遇到以下事项，除常规审查外，明确建议具有相应资质或经验的专业人员核查，不因给出通用模板而省略：

- 合同可能无效、交易涉嫌违法犯罪或规避监管；
- 公司担保、关联交易、股权控制权、国有资产、招投标或政府采购；
- 建设工程资质与实际施工、房地产权属和登记、金融或证券业务；
- 劳动用工、消费者、人身损害、产品安全、环境保护；
- 大规模个人信息、重要数据、跨境数据或关键信息基础设施；
- 复杂税筹、跨境交易、出口管制、制裁、反垄断；
- 外国法适用、境外仲裁或判决承认执行；
- 争议已发生、诉讼时效或除斥期间临近、保全或执行期限临近。

升级建议应指出需要核查的具体问题和材料，不使用空泛的“请咨询律师”代替已能完成的审核。

## 六、报告中的法律引用格式

推荐：

> **S-ID**：S-001  
> **法律命题**：……  
> **依据**：《……》第……条第……款（制定机关／文号；施行及修正状态）。  
> **官方来源**：URL（核验日期：YYYY-MM-DD）。  
> **本案适用**：原文事实 → 构成要件 → 例外 → 结论；事实不足处列为待确认。  
> **结论属性**：无效风险／可撤销风险／约定不明补缺／商业风险等。

如果只有商业经验依据，写“基于履约与谈判风险的建议”，不要附上无关条文装点结论。
