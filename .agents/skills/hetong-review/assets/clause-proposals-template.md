- [ ] 每项条款均对应已确认 finding；已按闭合授权逐句反查，没有未确认的新增、收窄、合并例外或附条件。

- [ ] 条款的主体、定义、日期、金额、税率、比例、期限和附件名称与基线一致。
- [ ] 没有以保护我方为名设置明显无效、不可执行或严重失衡的安排；我方提供的格式文本已检查异常条款提示说明义务及证据。
- [ ] 每个核心条款均已用相应失败场景反推“触发—程序—证据—救济—退出”能否走通。
- [ ] 验收—付款—质保—违约—解除—争议解决已做联动检查。
- [ ] 责任限制、例外、违约金、赔偿、退款及第三方索赔不冲突、不重复获赔。
- [ ] 涉及知识产权时，付清条件、部分履行/解除结算、成果移交和背景许可相互衔接，没有付款后仍不能使用成果的权利真空。
- [ ] 法律底线与可谈判商业事项分开，未把用户风险接受表述为合法化。
- [ ] 所有待确认变量和残余风险已集中披露。
- [ ] 本阶段没有改写原件；`readonly-check` 通过。后续写入、关闭核验和最终 SHA256 登记另行进入修订/完善流程。
