# 风险模式库

常见交易结构与合同条款的风险模式及对策。供审核模式定性问题、完善模式
开处方时引用。项目规则有特别约定的，从其约定。

## 一、交易结构风险

### 1. 定性错位（名为 X 实为 Y）
- **风险**：合同名称/措辞与实际履行不符，税务按实质课税、法律按实质
  认定；包装比不包装更糟（还多一层"故意规避"的观感）。
- **对策**：措辞忠实于真实权利义务；交易定性（买卖/服务/工程/代理）
  先行确定，全文术语与税目随之统一。

### 2. 票实不符（区分差错、行政与刑事风险）
- **风险**：发票品目、型号、金额与实际交付不符，需要核查真实交易与开票依据。
  区分可更正差错、行政违法和具备构成要件的刑事风险，不因单项不一致直接定罪。
- **对策**：发票按实际交付开具；替代交付备案＋实际清单签收；公对公
  收款；上游提供授权链/单据链；虚开损失由责任方全额赔偿条款。

### 3. 过票/通道化
- **风险**：中间方只开票不经手货权与风险，被认定无真实交易。
- **对策**：货权沿合同链流转（即使指示交付直发现场，单据注明"受×
  指示交付"）；中间方保留验收、付款、追偿等真实权义。

### 4. 背靠背断链
- **风险**：对客承诺的责任上游没接住，中间方独自兜底。
- **检查**：逐项比对范围、期限、上限、免责、违约金；上游质保/保修
  不短于对客承诺；质保金比例匹配。
- **法律边界**：《保障中小企业款项支付条例》禁止大型企业把"收到第
  三方付款"作为向中小企业付款的条件，也禁止按第三方付款进度比例支付；先核对订约时企业规模。
  适用禁令时应提出合法且独立确定的付款安排，不能只加兜底日期而继续保留被禁止条件。

### 5. 多主体绕单
- **风险**：上游/下游越过中间方直接交易，中间方商业价值流失。
- **对策**：客户保护/禁止绕单协议＋违约金（按绕单金额比例）＋收益
  返还＋解除权；白名单化合法直接联系（安全、原厂核验、监管）且须
  同步；关联主体规避一并禁止。

## 二、条款级风险

### 6. 验收僵局
- **风险**：付款以验收为条件，对方拖延验收则永远不付款。
- **对策**：异议期＋默示通过（"到货后 N 日内未提出书面异议视为合格"
  ）＋非己方原因逾期未到货/未验收的付款到期兜底。

### 7. 责任上限漏洞
- **风险**：上限无例外（对方故意违约也只赔上限）；或例外被其他条款
  架空。
- **对策**：区分法定不得免责与谈判例外。人身损害、故意或重大过失造成财产损失按民法典
  第五百零六条核查；知识产权、保密等例外须有约定或另行法律依据，不统称法定例外。
  是否设置上限及范围按我方角色和用户目标判断；检查兜底条款不吞掉特别约定。

### 8. 管辖约定无效
- **风险**：违反专属管辖（建设工程施工→工程所在地；不动产→所在地
  等）或与争议无实际联系（依争议类型而定），约定无效等于裸奔。
- **对策**：先识别合同性质是否落入专属管辖；普通商事选与争议有实际
  联系且对己方便利的地点；仲裁机构名称必须准确唯一。

### 9. SLA 不可考核
- **风险**：性能承诺无量化指标、无测量方法、无数据来源，争议时无法
  举证。
- **对策**：指标＋保证值/努力值＋测法＋测量工具/数据来源＋违约计算
  ＋上限＋非己方原因免责。

### 10. 变更程序空转
- **风险**：口头变更即施工/供货，事后无法结算；"登记即生效"与"批准
  才生效"并存导致解释打架。
- **对策**：书面变更单制度；登记≠批准；紧急变更的范围与事后确认时限；
  与主合同的变更条款效力顺位写清。

### 11. 付款与交付不同步
- **风险**：先款后货无担保，或先货后款无保障。
- **对策**：进度款与交付里程碑绑定；尾款与验收绑定；大额预付要求
  锁货证明/保函；逾期付款与逾期交付的违约金对等。

### 12. 证据链断裂
- **风险**：履行过程无单据闭环，争议时无法证明"交付了什么、何时、
  谁签收、是否合格"。
- **对策**：合同写明单据要求（订单、物流单、序列号清单、签收单、
  验收记录、发票、付款凭证一一对应）；变更/指令书面化。

### 13. 定义条款陷阱
- **风险**：定义过宽殃及池鱼（"设备"定义含赠品/备件则质保义务扩大）；
  定义与其他条款冲突。
- **对策**：定义与使用场景逐一核对；排除项明列；修改定义后全文检索
  该词的每一处使用。

### 14. 解除后真空
- **风险**：只写解除条件，没写解除后怎么办（已付款、已交货、在制品、
  保密义务、质保存续）。
- **对策**：解除后果专款：结算规则、返还、过渡义务、存续条款清单。

### 15. 通知条款形同虚设
- **风险**：没有视为送达规则，对方玩失踪程序就卡住。
- **对策**：送达方式＋视为送达（寄出后 N 日/邮件发送成功）＋地址变更
  未通知按原地址送达有效。

## 三、税务口径提示

- 税目税率结合**纳税义务发生时点**、履行期间和新旧法过渡核对；引用法规文号前用 web 工具
  核验，不凭记忆；
- 一项交易涉及多税率的处理规则、简易计税的适用条件与期限、混合销售
  定性，均随政策调整——每次审核时复核，不沿用旧结论；
- 含税价换算：税额 = 含税价 ÷ (1 + 税率) × 税率；不同税率部分分别
  核算的，合同价款须分列。
