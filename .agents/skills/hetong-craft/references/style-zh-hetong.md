# 中文合同语言与体例规范

润色模式的判定基准；起草、修订的语言标准。项目规则或同族文件另有体例
约定的，从其约定（项目体例优先于本通用规范）。

## 一、用词

### 1. 情态动词（义务强度词）——全文统一，不得混用

| 词 | 含义 | 用法 |
|---|---|---|
| 应当 | 强制性义务 | 合同主义务的默认表述 |
| 应/须/必须 | 同"应当"（一份文件内只选一套，不混用） | 同族文件保持既有选择 |
| 不得 | 禁止性义务 | 禁止行为 |
| 有权 | 权利 | 权利性条款 |
| 可以/可 | 授权性（可为可不为） | 谨慎使用，确认不是想写"应当" |
| 视为 | 法律拟制 | "视为验收合格""视为送达"——效果明确，慎用 |

### 2. 术语一致

- 同一概念：全文同一词（"设备"就全文"设备"，不忽而"货物"忽而"产品"）；
- 定义过的简称：定义后**只用简称**（"以下简称'甲方'"之后不得再写全称）；
- 不同概念必须不同词：如"交付"与"验收"是两个法律事件，不得混用；
- 合同族内跨文件术语统一（本合同的"随附交付作业"在关联合同中同义表述
  必须一致）。

### 3. 时间与数字

- 期限写明**起算点**与**单位**："自验收合格之日起 10 个工作日内"，
  不写"10 天内付款"（哪天起算？自然日还是工作日？）；
- "以上、以下、以内"含本数有法定默认，但涉及金额节点时写明"含/不含"
  更稳妥；
- 金额：小写（￥1,000,000.00）＋大写（人民币壹佰万元整）并列；
- 比例写清基数："合同总价的 5%"而非"5%"；
- 日期统一"×年×月×日"或"YYYY-MM-DD"，一份文件内不混用。

### 4. 歧义高发结构

- **"和/或"连用**："A 和 B"（并列都要）/"A 或 B"（择一）/"A 和/或 B"
  （两者或其一）——选错即改变范围，列举超过两项时用"下列任一/全部"
  并加冒号分号分层；
- **顿号歧义**："A、B 和 C"与"A、B、C"的最后并列关系要无歧义；
- **指代**："其""该""上述"所指对象必须唯一可辨，一段话里出现两个以上
  主体时改用明称；
- **否定范围**："不包括 A 和 B"是都不含还是只不含其一，须写明；
- **"等"字**："包括 A、B 等"是列举穷尽还是示例（"等"前加"包括但不限
  于"则为开放式）。

## 二、体例

### 1. 编号层级

推荐层级（同族文件保持一致，不中途换体系）：

```
第一条　（条，汉字数字）
　1.　（款内编号或独立款，阿拉伯数字）
　（1）（项）
　　① （目，少用）
```

- "第×条"引用必须指向真实存在的条；增删条款后全部引用复核一遍；
- 款不编号的（自然段式），引用时用"第×条第×款"；
- 编号后不加标点或统一加全角空格，全文统一。

### 2. 首部与签署

- 当事人信息块字段统一：全称、统一社会信用代码、地址、法定代表人、
  联系人、邮箱；
- 占位符统一风格（如 `【待定：×××】` 或 `［　］`，沿用文件既有风格）；
- 签署页：盖章栏主体与首部当事人全称一致。

### 3. 附件与引用

- 附件编号连续（附件一、附件二…），正文引用与附件标题逐一对应；
- "本合同附件是本合同不可分割的组成部分"类效力条款存在且位置正确；
- 多份合同共用附件时，各自装订同名附件并保持一致，不跨合同引用编号。

### 4. 标点与字符

- 中文正文全角标点；西文缩写、型号、编号中的符号保持半角；
- 括号层级：先用全角（），内部再分层用〔〕或［］，不嵌套同一括号；
- 全文同一字符集习惯（如"％"与"%"不混用，推荐半角 %）。

## 三、段落写作

- 一条一款一事；一款只规定一个义务/权利；
- 义务四要素：义务人、行为、期限/标准、违反后果（在同条或可指向的
  违约条款中闭环）；
- 先一般后特殊；例外、但书紧跟主句；
- 每个"应当"都能回答：谁、在什么时间前、做到什么程度、否则怎样——
  回答不了的条款不可执行，润色时标注出来（实质问题转完善模式处理）。

## 四、英文缩写与外来词

- 专业缩写首次出现括注中文或全称（如"服务等级（SLA）"），其后统一用
  一种写法；项目规则有语言加固定稿的从其约定；
- 外来概念（BOM、SLA、PMO 等）的使用与项目既定口径一致。
