# Word/WPS 原生审阅显示与配色

用于已有授权的Word修订、批注工作，由hetong-craft、hetong-review共用。目标是在当前客户端能力范围内，让本轮批注对应文字呈现较浅的原生高亮、修订文字呈现较深且易辨的原生标记，并尽量避开历史审阅颜色。它是显示检查，不扩大合同内容、署名或格式修改权限。

## 不改变正文格式

只使用客户端原生审阅显示功能。不得为配色增改正文或批注文字的字体颜色、高亮、底纹、样式、主题、形状或图片，不向DOCX注入模拟颜色；不得通过改作者姓名、缩写、历史归属或拆分身份换取颜色。

必须保留真实修订、批注范围和历史审阅。这里的“批注高亮”指正文中被批注文字的原生选区显示；批注框边框、头像或批注文字的颜色不能替代这一目标。选择焦点产生的临时高亮与可配置的审阅显示分别记录。

## 先检查客户端能力

1. 先完成原有Word深读和基线锁定。确认目标客户端、版本、平台和批注模式；使用已有连接或原生界面/接口检查当前审阅视图，无须为每条批注重复打开软件。
2. 查看相关历史批注、插入、删除及其他修订的当前可见颜色，辨别设置按作者、按标记类型还是仅作用于当前选择。没有查看全部相关标记时，说明覆盖范围，不声称全篇已避色。
3. 核对接口或选项的实际作用：批注原文高亮、批注框、插入文字、删除文字各是什么，是否只能改应用全局设置，是否会重映射历史标记或影响其他打开的文档。仅看到可写的属性或返回成功，不等于目标界面产生了效果。
4. 文件中的作者记录、`w:color`、`w:highlight`、`w:shd`及主题颜色不是客户端原生审阅颜色表；不能只解析OOXML就声称读到了当前审阅高亮，也不能以无头渲染替代目标客户端证据。

## 在能力范围内指定

- 当前客户端支持限定到本轮新增标记、且不影响历史显示时，由同一操作者或统一计划选择其原生支持的深浅颜色；先排除已见同色、近似色和低对比度组合，再按实际界面验证。原生色盘不支持的自定义色值不得假设可用。
- 配色方案随Word工作包统一交接，不能让不同子代理各自改审阅选项。同一处同时有批注与修订时，分别检查文字、删除线/下划线和批注选区是否仍能辨识。
- 只有全局标记类型颜色可改、会改变历史显示、按作者颜色不可指定、现代批注不响应设置，或无法确认设置范围时，保留原生显示。不得为满足配色而切换旧版批注、修改全局偏好或隐藏历史标记；用户另行明确允许的显示调整仍需保留恢复值并验证影响范围。
- 客户端不可用或没有可靠的原生控制能力时，继续原有的合同处理及结构检查，记录“原生配色未验证/未设置”。不为配色另接服务、不强制启动不受支持的宿主、不反复请求同一许可。

配色能力不足不阻断已授权的审核、修订或批注交付。保留真实署名、修订和批注定位，简洁披露显示限制；不承诺跨电脑、跨客户端或再次打开时仍保持相同颜色。

## 验证与交付记录

能设置时，在目标客户端实际检查相关新旧标记、批注选区、插入/删除和必要的重新打开显示；只在检查覆盖范围内报告无明显撞色。临时视图调整在验证后恢复，除非用户要求保留；不动其已有全局偏好。

同时核对没有因配色新增正文/批注的颜色或底纹格式、格式修订、作者变化及历史标记变化。合同内容修订和配色操作分别留证；“接受本轮/拒绝本轮”验证仍按原有流程完成，不能用颜色相同或不同判断修订归属。

使用已有日志或回执记录：客户端与版本、所见历史颜色及范围、作用域、尝试设置与可见结果、必要的截图/接口证据和限制。至少区分：

- **已设置并验证**：原生显示实际生效，注明客户端及检查范围。
- **保留原生显示**：不支持独立配色或会影响历史，注明原因。
- **未验证**：缺少目标客户端或界面证据，不把参数、XML或子代理自报当作显示结果。

## 已知产品边界

以下依据核验于2026-10-29；不同版本使用前核对实际能力，不把文档示例当作实机通过：

- [Microsoft：修订颜色](https://support.microsoft.com/en-us/word/change-the-track-changes-color)：按作者颜色由Word分配；按标记类型固定颜色会影响同类标记，颜色设置受本机影响。
- [Microsoft：CommentsColor](https://learn.microsoft.com/en-us/office/vba/api/word.options.commentscolor)：是应用选项，重新设计的批注体验可能不产生可见效果；不能据此保证正文批注选区的深浅色。
- [WPS：修订及批注外观](https://www.wps.cn/learning/room/d/326991)：提供插入、删除、批注及按作者颜色选项；是否能只作用于本轮及正文选区，仍须核对具体版本和界面。
