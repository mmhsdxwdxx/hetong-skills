# 甲方来源编号定位索引

本入口保留原A编号。现行条款库以[分类条款入口](buyer-consolidated-clauses.md)链接的Markdown正文及其[派生索引](buyer-clause-catalog.json)为准，先按[类别选择流程](buyer-category-selection.md)确定范围，不把来源编号全部作为默认必加条款。

| 来源编号 | 类别 | 整合条款 |
|---|---|---|
| A01 | 必要条款 | M01 保函受益人、开立交付与生效 |
| A02 | 其他条款 | M02 BIS限制、政府禁令与不可抗力 |
| A03 | 必要条款 | M03 保函有效期、展期退款、索赔与余额管理 |
| A04 | 共管条款 | M04 资金共管账户与U盾权限 |
