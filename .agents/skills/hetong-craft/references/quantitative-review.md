# 数字、指标、时间轴与现金流

> 本文件中的比例、期限和数字是买卖条款库的商业核对框架；具体交易参数按本次合同和用户确认值替换，不把示例值当作通用默认。
> 本文件分列甲方与乙方量化口径。甲方按 A01—A24 和实际保函、共管账户安排核算，不套用乙方责任上限或减额公式。

## 甲方采购与上下游衔接

先按[类别选择](buyer-category-selection.md)锁定预设条款范围。类别筛选不豁免对当前合同已有金额、税率、期限及矛盾的复算，但不能据此自动加入未选类别的商业义务。

配合 [A05—A16](buyer-upstream-checklist.md) 和 [A17—A24](buyer-normalized-clauses.md) 使用。无下游交易时不虚构下游数据；本节不设通用首付比例、缓冲天数或保修补偿比例。

| 核对项 | 方法及边界 |
|---|---|
| 上下游首付 | 上游首付＝上游总价×上游比例；下游回款＝实际到款。比较比例之外还比较金额，不用同一个总价相乘 |
| 资金缺口 | 按事件列实际可用流入、上游付款、税费、开函保证金和其他实际流出；阶段缺口＝max(0,累计实际流出－累计可用流入)。资料缺失时只报告已知项差额或条件结果，不声称完整净融资需求 |
| 担保覆盖 | 分别列未结清预付款、实际有效保证金额、索赔条件和期限。担保面额不等于可立即收回金额；不把买方责任上限设成乙方默认的 3%/5% |
| 交期缓冲 | 上游到货至下游义务到期的间隔，应与运输、检验、补测、换货及非营业日对照；时长未知用变量，不自行承诺缓冲天数 |
| 不合格与换货 | 按对应设备价款、复测次数、换货期限和费用归属核对，不把整批合格款无条件与单台争议捆绑 |
| 原厂保修 | 按交付时实际剩余期与目标期比较；5%—10%仅为待选择区间，金额上下界可演算，不代选最终比例 |
| 下游赔付 | 区分上游退款、下游退款、违约金、赔偿、利息及维权费用；核对同一损失的返还、抵扣、银行赔付和已获补偿，避免重复受偿 |

新增条款另核对以下项目；原始草稿数值仅用于候选演算，不作为默认已确认值。

| 核对项 | 方法及边界 |
|---|---|
| 逾期开票 | 按每一计罚日的尚未开票含税余额U_d计算：合计违约金＝Σ(U_d×0.0007)。部分补开按确认的计日口径减基；不按票张数重复计罚，不把税额误作货值基数 |
| 开票期限 | 验收完成事件→原稿7—10个工作日开票区间→逾期自然日。保留本轮区间，不降格为参考目标、不改15日、不擅自取端点；履行解释和逾期起算未闭合处单列澄清 |
| 税务可用额度 | 同月尚可用不含税额度＝核定/调整后额度－已占用额度；13%适用时，批次所需额度＝对应含税开票金额÷1.13。核对资料时效、期间及其他占用，不把总额度、含税货值混比 |
| PO与SN | 按本轮原稿保留收到甲方预付款后2周、PO提供后4—7周及分批提供全部SN；两周可换算14自然日。多笔款项、多份PO如何对应批次未明时单列问题，不替换起算事件或期限 |
| 保函查询违约金 | 候选固定日额100000元×按已确认口径计算的违约天数；先确定公示期限、补正期限、计罚起算事件及5日解除门槛，不把这些事件混为一个日期 |
| 保函税损覆盖 | 开票到期日晚于验收时，检查承保义务、有效期及交单窗口是否仍覆盖税损；查询成功不等于有该项承保，面额也不等于该项可索赔额 |

付款时间与比例联动先过中小企业付款规则，不以资金缺口分析授权违反强制性支付要求。A08 涉及保函生效条件冲突时分别展示原 A01 与待决设想的现金/担保空窗，不替用户选方案。

## 乙方参数与核算

执行[下游保函责任原则](downstream-guarantee-policy.md)，按本单已确认的实际保额、所保责任、可用余额、已兑付/抵扣及尚未覆盖金额逐笔核算；预付款结算必须与保函机制闭合，不把缺失参数当零，不用现金退款加保函赔付建立双重回收。

以下乙方专用公式、时间索引和限制保持 B01—B11 口径；指标勾稽方法可复用，商业数值及索赔限制不可移植到甲方。

从原文记录数值、单位、币种、含税口径、来源、适用批次及待确认项。用 Decimal 等十进制工具复算金额，保留公式与结果；区分工作日、自然日和小时，日期计算须有起算规则、日历及节假日依据。缺参输出公式，不编造数值。

令 T 为含税总价，N 为总台数，a 为本单预付款比例，G₀为确认的初始保额、G为当前可用余额；分项额度单列。金额及比例全部来自本单明确事实，不设默认履约或专项罚率。

| 核对项 | 公式及检查 |
| --- | --- |
| 数量与价款 | 分项金额＝数量×对应单价；总价＝分项金额与约定费用/折扣之和；批次数量之和＝N；大小写、币种、税口径一致 |
| 税额 | 税率和计税口径确认后：不含税价＝含税价÷(1＋税率)，税额＝含税价－不含税价；多税率分项计算并核对舍入 |
| 预付款 | A＝T×a；抵扣合计不得重复或超出余额；抵扣不是第二次现金支付 |
| 批次尾款 | 正常场景 F_i＝V_i－D_i，V_i 为批次价款、D_i 为预付款抵扣；另有扣款、退款、质保金则单列调整 |
| 全部完成 | 无退款、折让及其他调整时 A＋ΣF_i＝T，ΣD_i＝A；未结款及未抵扣预付款归零；其他情景按实际调整闭合 |
| 初始担保 | 按本单确认保额G₀及分项安排复算，分项之和须与总额一致；不自动以预付款加历史比例计算 |
| 逐台减额 | 按约定对应初始额度÷N，N＞0；只有满足约定并签署验收确认单的合格交付台数进入计数，核对减保后持续覆盖 |
| 责任及兑付 | 以本单确认的保函责任额度统一核算；可索赔额至多为min(应由保函处理的权益或责任,可用担保余额)，不叠现金罚则；法定例外独立核验 |
| 延迟费用 | 复算约定基数、费率、适用天数、宽限期及限额；不擅自年化、复利 |

不同型号或单价设备仍先按底线“初始额度÷总台数”复算，再检查等额减保与实际抵扣是否一致。不能静默改为按价值减额；不匹配时列明差额、影响及配套保护，改变底线的方案单独标识。检查尾差及最后一台/一批清零规则。

## 担保、责任、索赔分账

按本单实际保函建立台账；只有明确分账时才分列本金与履约担保。登记合格交付、预付款抵扣、银行赔款与减额，不以同一事项重复扣减。预付款结算与赔款用途须对应，不另设乙方现金退款；历史已发生的退款如实记录，不据此设定未来退款义务。

可申请金额依据未获清偿的对应权益、实际承保和有效可用余额核算，不能只凭面额判断。质量、发票、售后、质保等相关合同金钱责任一并检查覆盖；未纳入保函或索赔期限不足应列缺口，不默认保函外另行赔付，也不声称已经免责。责任额度、可索赔额、担保余额和依法不能限制的责任分别说明。

负担保余额、重复受偿、超收或合格交付台数超总数应回查事件和原始约定，不直接修成零掩盖错误。

## 指标勾稽

逐层核对单台配置与整批数量、GPU/CPU/内存/存储/网卡等规格与报价、技术附件、交付清单和验收单是否一致。指标须明确单位、单台或集群口径、测试工具与版本、负载、持续时间、阈值和失败处理；总量不等于可用容量，理论峰值不等于实测性能。只复算合同实际出现的指标，不自行增设新的性能承诺。技术规格有争议时查制造商当前官方资料并记录版本，不能凭印象改型号。

## 时间轴

履约事件的展示统一按[合同履约时间轴规范](contract-timeline.md)：固定日期栏＋我方现金流及付款义务／交付与担保／发票（万元），一要点一段。该规范及其虚构模板只规定表达方法，不改变本节甲乙方适用边界，也不把以下基线期限当成本次交易事实。

按实际合同建立事件表：签署/生效、20 个工作日内开函、全部预付款到账与保函生效、交付计划、提前 5 个工作日到货通知、收到通知后 3 个工作日内启动验收、开始后 72 小时完成及书面顺延压测、压测合格后 24 小时内尾款、货权转移与提货、下一批、最后一批交付后 30 个自然日内保函失效。

这只是基线事件索引，不能自动认定可执行。重点检查：

- 提前 5 个工作日通知与收到通知后 3 个工作日验收，是否造成货未到先验收；验收完成、压测顺延、验收合格是否有冲突。
- 开函、付款、保函生效是否循环或存在空窗；20 个工作日开函、不可归责免责和不得因未开函解除对我方的影响。
- 24 小时尾款遇非营业日的可执行性；一批延付阻断下一批的连锁后果；不合格设备是否不当绑定合格设备的结算。
- 部分取消、长期未交付及换货时“最后一批交付”的含义；“30 日内失效”是否确定到期日；宽限期、退款到期、索赔送达与保函到期/延期是否相容。
- 货权、风险、占有/提货、发票与质保起算是否错位，不能视为同一事件。

无具体日期则用相对事件，不伪造日历；先查优先适用条款，再判断矛盾。

## 现金流与利益相关方

从我方角度定义现金流入为正、流出为负。按事件/批次记录付款人、收款人、金额、现金或账面抵扣、条件、到期日、累计净现金流、未抵扣预付款、未收尾款及担保覆盖。抵扣单列，不能重复计入现金流。

按交易实质分析正常交付、部分不合格/延期、部分取消退款；有 BIS 条款时分析受影响未交付部分取消。买方侧关注预付款、合格货物、货权、退款与担保空窗；卖方侧关注备货占款、验收、尾款、下批供应、退款及开函资金占用。无采购成本、开函保证金或融资数据时不能量化净融资缺口。

暴露额不是损失。对明确定义的对象（如已付且未被货物/退款结清的预付款）计算保障差额，并列出担保有效性、兑付条件等限制。未给资金成本率不编造利息，情景假设与事实分开。检查指定开函方、银行、上游、最终用户及物流是否让本方承担无追偿保障的付款、交付、税务或索赔责任。

每项风险给出数字、触发事件及修改位置；配套建议不得静默恢复底线删除的验货前资料义务或未开函解除权。
