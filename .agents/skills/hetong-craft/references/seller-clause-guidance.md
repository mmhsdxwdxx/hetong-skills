# 乙方两段式条款：使用说明与依据

适用于我方为服务器销售方或交付方。B01—B11分类入口见[乙方条款](seller-baselines.md)，实际正文只在相应分类Markdown中维护。按用户2026-10-30逐条改稿分类：B01—B09、B11为必要条款，B10为其他条款；每条分为“实质要求”和“范例条款”；本说明不属于合同正文。

## 使用原则

1. 以用户本次指令及已确认的乙方基线为准。借鉴甲方版的是写法，不是将甲方保护目标倒置或移入乙方条款。
2. 范例默认采用原有3%总体上限和履约比例；单笔已经明确采用5%时，在总体上限、履约金额、组合保函及相关引用中同步改为5%。原基线最高5%，未获通用变更授权不另设比例。
3. 保密专项1%计入总体上限，不是总体3%或5%之外再加1%。本金支付及本金返还与违约补偿分账，不能用补偿上限截留本金。
4. 原文件中的附件2、3、4、6、7和第7.8、7.11、8.4等编号仅为历史定位，落入实际合同时按条款名称核对并重新编号。历史32台、40%/60%、2640万元等不是固定参数。
5. 法律依据、核验事项、删除操作、例外解释及内部B编号不复制进范例正文；已获准修改时再按实际合同适配。只审任务仍只输出诊断。
6. 不自动恢复旧第8.2—8.4条整段、15日举证要求、未确认的永久保密条款，或甲方版的3日开函、PO两周、4—7周SN、无条件即时生效等要求。

## 各项适用与填项

| 编号 | 适配与核验 |
|---|---|
| B01 | 18家银行名单完整保留；这是用户选定的接受范围，不是对当前全部银行的分类清单。实际开立时核验银行身份、存续及出函能力。非名单银行、模板实质偏离、指定方开立三种情形分别处理。 |
| B02 | 本例中乙方是受保护的我方，甲方是合作方；不得因采用双方措辞而免除乙方依法应承担的责任。合法佣金不等于所有佣金均合法。 |
| B03 | 只使用已确认的保密违约赔偿条款。损失可证明、直接损失、累计1%、计入总体上限、法定例外均保留；不增加永久保密期限。 |
| B04 | 默认3%，明确5%才切换；与B03/B09联动。上限不是最低赔付额，也不是保函必须见索即全额赔付的承诺。全部批次、全部违约和银行已付补偿合并核算。格式条款效力及法定不得限责事项须独立核验。 |
| B05 | 仅限BIS措施直接造成的合法交付障碍，且合理措施后仍无法排除；不是所有处罚或经营困难均可免责。取消仅影响未交付部分，送达生效、无需另获甲方同意；对应全部已收款仍须按约退还。不得据此实施违反强制性法律的行为。 |
| B06 | 保留5工作日通知、3工作日启动、72小时验收、24小时尾款及GPU完整压测的书面合理顺延。原“提前5工作日”没有明确以何事件为基准，范例用【约定的提前通知基准日】保留；使用前核对通知、货物可验及到场时间是否能够同时满足，不暗改数字或起算条件。 |
| B07 | 20工作日与不可归责免责保留；删除仅因未开函导致自动解除或约定解除权的内容。该处理不擅自改成甲方版付款前即生效要求，也不把可协商的合同解除安排写成排除一切法定权利。 |
| B08 | 是按阶段识别的删除规则，范例将其转为双方的合同约定。不因出现PO/SN/PI就删除验货当时或验货后的核验义务；也不删除法定资料义务。 |
| B09 | 填总价、预付款比例、总台数、两部分初始额度与宽限期。按对应初始额度÷总台数等额减保，不静默改为按设备价格比例减保。合格交付、退款、银行赔付逐笔核账，同一本金不重复扣减。 |
| B10 | 仅整理原有产品名称、规格型号等信息不符的民事赔偿分配，不扩大为一切开票违约免责。不得把该约定解读为允许虚开、不开发票、免除税务义务或排除行政刑事责任；法定不得免责部分不适用。 |
| B11 | 保留“全部预付款到账才生效”和“末批交付后30自然日内失效”。30日是范围上限，不自动改成固定第30日；具体到期日或事件必须填明，并同步到实际保函。 |

## 担保与限额核算

以含税合同总价T、总台数N、预付款比例a和履约比例p为输入，N须大于0：

- 初始本金担保G₀＝T×a，初始履约担保H₀＝T×p。
- 每台合格交付的本金减额＝G₀÷N；履约减额＝H₀÷N。
- 仅在双方签署验收确认单后按合格台数减额。退还或银行支付的同一本金另核剩余额度，避免与交付减额重复。
- 设到期应退而未退本金为R，宽限期后依法依约应赔而未付交付补偿为C，现时本金与履约余额分别为G和H，内部合同可主张额至多为min(R,G)＋min(C,H)，并继续受总体/专项责任限额约束。
- 公式不是银行付款保证。担保范围、减额、单据及失效条件以依法有效的实际保函核对；正文、模板和实函不一致时单列问题。
