# 乙方两段式条款：使用说明与依据

适用于我方为服务器销售方或交付方。B01—B11分类入口见[乙方条款](seller-baselines.md)，实际正文只在相应分类Markdown中维护。按用户2026-10-30逐条改稿分类：B01—B09、B11为必要条款，B10为其他条款；每条分为“实质要求”和“范例条款”；本说明不属于合同正文。

## 使用原则

**版本优先级：** 下游供货执行[下游保函责任原则](downstream-guarantee-policy.md)。新旧线程后续加载均适用；历史范例不覆盖新版规则。其他不冲突的适用性要求继续有效。

1. 以用户本次指令及已确认的乙方基线为准。借鉴甲方版的是写法，不是将甲方保护目标倒置或移入乙方条款。
2. 责任以本单明确的保函金额、范围及结算机制核对，不从历史模板自动继承总体或专项罚率，也不把保函与预付款的差额自动改成违约金。
3. 保密等合同金钱责任并入保函覆盖，不另叠现金罚则；预付款按保函机制结算，不另行现金退还，也不等于没收。是否分账及各分项额度依本单确认。
4. 原文件中的附件2、3、4、6、7和第7.8、7.11、8.4等编号仅为历史定位，落入实际合同时按条款名称核对并重新编号。历史数量、付款比例和金额均不是固定参数。
5. 法律依据、核验事项、删除操作、例外解释及内部B编号不复制进范例正文；已获准修改时再按实际合同适配。只审任务仍只输出诊断。
6. 不自动恢复旧第8.2—8.4条整段、15日举证要求、未确认的永久保密条款，或甲方版的3日开函、PO两周、4—7周SN、无条件即时生效等要求。

## 各项适用与填项

| 编号 | 适配与核验 |
|---|---|
| B01 | 18家银行名单完整保留；这是用户选定的接受范围，不是对当前全部银行的分类清单。实际开立时核验银行身份、存续及出函能力。非名单银行、模板实质偏离、指定方开立三种情形分别处理。 |
| B02 | 采用双方对等的廉洁正文，与甲方M21一致；人员行为依法归责，不一概免除所属方责任。正常履约及合法佣金不当然代表违法参与；可书面解除受影响部分并依法追偿，不免除法定不得免责的责任。 |
| B03 | 保留可证明的直接损失与法定例外；乙方责任并入保函额度，不设默认专项罚率，不增加永久保密期限。 |
| B04 | 与B03/B09联动，使用本单确认的保函责任额度；覆盖全部相关合同金钱责任，不另行现金退预付款。额度不是最低赔付额，格式条款与依法不得限责事项独立核验。 |
| B05 | 仅限BIS措施直接造成的合法交付障碍，且合理措施后仍无法排除；不是所有处罚或经营困难均可免责。取消仅影响未交付部分，送达生效、无需另获甲方同意；预付款结算衔接保函，不另设现金退款义务；依法不得排除的责任及实际承保缺口独立核验。不得据此实施违反强制性法律的行为。 |
| B06 | 保留5工作日通知、3工作日启动、72小时验收、24小时尾款及GPU完整压测的书面合理顺延。原“提前5工作日”没有明确以何事件为基准，范例用【约定的提前通知基准日】保留；使用前核对通知、货物可验及到场时间是否能够同时满足，不暗改数字或起算条件。 |
| B07 | 20工作日与不可归责免责保留；删除仅因未开函导致自动解除或约定解除权的内容。该处理不擅自改成甲方版付款前即生效要求，也不把可协商的合同解除安排写成排除一切法定权利。 |
| B08 | 是按阶段识别的删除规则，范例将其转为双方的合同约定。不因出现PO/SN/PI就删除验货当时或验货后的核验义务；也不删除法定资料义务。 |
| B09 | 填实际保额、总台数、分项安排及索赔条件；不默认历史履约比例或现金退款前置。按约定初始额度÷总台数等额减保，核对减保后持续覆盖，防止抵扣、交付、银行赔付重复扣减。 |
| B10 | 仅整理原有产品名称、规格型号等信息不符的民事赔偿分配，不扩大为一切开票违约免责。不得把该约定解读为允许虚开、不开发票、免除税务义务或排除行政刑事责任；法定不得免责部分不适用。 |
| B11 | 保留“全部预付款到账才生效”和“末批交付后30自然日内失效”。30日是范围上限，不自动改成固定第30日；具体到期日或事件必须填明，并同步到实际保函。 |

## 担保与限额核算

以本单确认的初始保额G₀、当前可用余额G、应由保函处理的权益或责任C为输入；如有分项，按确认的分项分别核对，不自行拆分或采用默认比例。

- 已确认按台数N等额减保时，每台减额＝对应初始额度÷N，N须大于0；核对分批与尾差，减保不能遮蔽尚需覆盖的责任。
- 可申请兑付金额至多为min(C,G)，仍须满足实际保函的担保范围、单据和期限；分项额度不可擅自串用。
- 银行已付、预付款抵扣和其他已履行部分按对应权益逐笔核账，避免重复减额或受偿；不再默认“先现金退款再赔违约金”。
- 公式不是银行付款保证。未生效、不足额、到期或不承保须列缺口，不能直接将全部责任归零。

## 廉洁条款法源补充（2026-11-02）

M21与B02采用同一份双方对等正文。依据[现行反不正当竞争法第八条](https://www.cnipa.gov.cn/art/2026/5/20/art_104_206437.html)核对工作人员行为归责和佣金明示、入账要求；依据[民法典](https://www.court.gov.cn/zixun/xiangqing/233181.html)第一百七十条、第五百零六条、第一千一百九十一条核对职务行为及不得免责的责任。不得将“人员个人实施”直接写成所属单位免责，也不得将正常交易或佣金的形式当作违法参与或当然免责的证明。
