# 甲方两段式条款：使用说明与依据

本说明服务于A01—A24的选择、填项和联动检查；不是合同正文。先按[类别选择流程](buyer-category-selection.md)确定本次范围，再从[单一条款目录](buyer-clause-catalog.json)读取所选20项整合条款中的相应内容。条款保持两段式和原分类；A02/A24第二部分保留为删除指引，不恢复旧范例。A来源编号与M整合编号并行保留。

## 使用原则

1. 本轮用户给定的数值、区间、起算事件和责任范围优先。历史合同、他人批注、公开范本和法律研究只用于核对术语、结构及执行边界，不授权改成另一笔交易的参数。
2. “实质要求”是业务核对目标；“范例条款”是在所列前提下的参考写法，不表示对方、银行、原厂或税务机关已经接受。示例的【】空项必须依具体交易补齐，不能用示例资料编造事实。
3. 只审任务按本次所选类别用实质要求识别缺口，不自动输出或写入范例正文。已获准修订时在该范围适配；未选类别不自动追加或删除，仍核对合同已有文字的一般法律、数字及逻辑问题。不把全部例文机械叠加。
4. 条款种类与甲乙方、风险等级、是否已确认分别记录。管理字段和A/B编号不自动写入给对方的合同或批注；条款标题、内外编号按目标合同统一。
5. 期限先核对起算事件、到达标准及工作日/自然日。7—10个工作日按完整开票窗口表达；PO后4—7周按满4周至满7周的完整窗口表达，避免误写为“第4周”而提前一周。不是改为单独7日、10日、4周或7周，也不引入15工作日。
6. 所有范例均受现行强制性法律和真实第三方文件约束。若要求存在法律或执行障碍，说明冲突并提出备选，不能静默反转用户目标或把银行承诺写成已落实。

## 各项适用与填项

| 编号 | 使用时重点 |
|---|---|
| A01 | 与A07整合为M01。3工作日来自A07的优先争取目标；指定受益人通知期、银行要求及模板附件仍待填。合同中写明独立付款不等于实际保函已符合；核对真实文本、受益人及索赔单据。 |
| A02 | 原稿已明确改为删除指引，类别为其他条款；只在选择该类别且获得对应修改授权时落实，不恢复旧范例。原目标包含出口管制、禁令等风险由乙方承担。不得把合同里的绝对措辞当成违法履约许可；强制性规则、实际因果关系、减损及证明义务分别核验。政府证明、公证或认证要求还需核对可取得性。 |
| A03 | 与A09整合为M03。保留末批交付后【30】日和到期前14日的来源表达；【30】仍按原基线作为交易填项。有效期既要满足最低日期，也须覆盖未结清义务，变更须落实到银行文本。 |
| A04 | 填账户、金额、时间、释放规则及交接期限。制单/审批权限、U盾保管和返还条件不得互换；共管并不当然产生对银行或其他债权人的优先权。 |
| A05 | 固定价与包干范围须与实际合同相符；明确是单价、总价还是订单价格。13%为本轮商业目标，仍须具备适用税率及开票资格，不采用虚假品名或违法开票。 |
| A06 | 附件一应锁定真实版本，存在下游时核对其技术附件，不能虚构下游。SN识别、处分权、交付、风险及所有权转移分开判断。 |
| A07 | 已纳入M01，不重复另加开函条款。3工作日是原始“优先争取”的目标；例文展示采用该目标后的写法，不将其说成每笔交易均已确认。下游尚未签约的安排不能被用来单方延期既有下游合同。 |
| A08 | 保留A01不以乙方收到预款为生效条件；曾出现的附条件保函设想没有替代A01。上游提前量、下游期限及双方告知安排按实际资料填，不自行加天数。 |
| A09 | 已纳入M03，保留其余额管理与配合义务。减额对应合格交付、预付款抵扣或退款等已确认条件；不照搬乙方等额逐台减保公式。每一变更均核对银行、受益人及当前余额。 |
| A10 | 保留100%测试、排除非设备原因、单台2次不合格、5工作日换货及三类费用。测试标准、地点和换货起算事件是填项，不新增性能阈值，也不把单台问题自动扩大到整批。 |
| A11 | 六类随货资料逐项核实。没有提取出图片不证明没有资料；补正方式及对验收/付款的影响按已确认合同处理。 |
| A12 | 先核对订约时企业规模和款项支付条例。大型企业向中小企业采购时，不得保留被禁止的第三方付款条件或按第三方回款比例支付；需填妥独立付款计划。无下游交易不使用回款关联部分。比例比较不能代替资金缺口核算。 |
| A13 | 保留3年目标，以及不足时事先披露、接受和价格体现机制。补偿比例只在原5%—10%范围内由用户确定；不代选，不把原厂保修与乙方合同质保混同。 |
| A14 | 保留禁止另售、质押或第三方交付和按货值约定高额违约金的目标。原稿没有比例和退款期限，范例留空；违约金数值不保证裁判全额支持。 |
| A15 | 保留五类下游责任和全额承担目标。不擅自加“须先付款”或“须经生效裁判”条件；核对因果、可预见性、减损及同一损失重复受偿。 |
| A16 | 信用风险触发事项逐一核实。范例用法院裁定受理表述破产/重整程序节点；若交易要求申请阶段即触发，须另按用户指令确定，不能把范例节点当作已确认选择。保留5工作日退款目标，但不能排除破产程序。付款、SN锁定或“共管”名称本身不证明存在取回权。 |
| A17 | 保留7—10工作日开票窗口、13%、每日万分之七及超10自然日解除本合同，不采用历史15日。新稿保留履行当日计罚、次日减基方案，仍须按本单核验执行。是否排除责任上限须单独明确，不能套用历史5%例外。 |
| A18 | 税务资料须证明实际审批通过，申请或受理回执不足以替代。按同月剩余可用额度及同一含税/不含税口径比较；2工作日从约定核验完成后起算，不从普通备货通知起算。资料的真实名称和官方核验方式据实际确认。 |
| A19 | 保留收到甲方预付款后2周、PO提供后4—7周和发货后提供物流凭证。多笔款项、多份PO的批次映射需明确；不能改成全部预款到账、PI提交或另加“完整性”门槛。PO/PI不当然证明所有权，SN真实性另核。 |
| A20 | 保留开函后2工作日、公示持续可查、100000元/日、逾期超5日；平台、补正期限、计罚/解除起点及计日口径留空，未改数值。合同提供担保义务违约与保函自身失效分开；平台故障查明原因，不直接判伪造。 |
| A21 | 与A06、A22整合为M06。按新稿，附件一优先范围是货物信息，不能退回为只限品牌，也不能扩展为覆盖全部合同。保留发货前逐台SN及附件一补充要求；与保交类别A19的进度提交、一般类别A11的随货交付分别核对，不自动互相代替。 |
| A22 | 作为M06独立子要求保留，没有因主题整合删除。主要设备名称含“服务器”；独立部件、配件、服务按真实内容列示，不为了名称一致改税目、报关属性或真实货物。 |
| A23 | 范例只授权必要的手续及单证记载调整。若拟允许等效配置、替代型号等实质调整，应另由用户确认边界，不以“海关政策等”推定获得权限。 |
| A24 | 原稿已改为一般条款下的删除指引，与其他条款下的A02分类不同，不跨类合并。选中两类且命中同一不利条款时仅执行一次并保留两来源记录；仅选一类不自动启用另一类。政策变化、不可抗力、情势变更、禁止履行及履行不能各自核验，不一律认定免责。 |
