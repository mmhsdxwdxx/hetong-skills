# 支出居间费的专项审核

用于我方支付居间费的中介合同，或其他合同中具有中介实质的条款。先核实服务内容与实际角色，不把一般服务费都视为居间费，也不套设备买卖的M/B条款、保函或压测要求。按本次授权交付诊断或修订，未定商业条件单列。

| 核对项 | 审核要点 |
|---|---|
| 服务与成果 | 核实交易机会、媒介服务、项目范围及成果证据，区分促成签约、主合同履行和回款；避免只凭合同名称或付款申请认定服务完成。 |
| 报酬与付款 | 写明计费基数、费率、上限、已付与应付；“主合同交易完成后付款”须具体定义完成事件及证明，并经本单确认。部分履行、解除、退款时如何结算分别检查，不默认交易未全部履行就无报酬请求权。 |
| 发票 | 核对居间方身份、实际服务品目、票种、税率或征收率、含税价及开票时限；票据内容与真实业务一致。税率按纳税人、业务及当期政策核验，不套设备销售税率，也不承诺自然人必能提供某类专票。 |
| 税差与扣缴 | 税差补偿是协商项，明确形成原因、计算基数、证明和承担范围，不默认按票面税率差赔偿或保证抵扣。向自然人付款时另核对所得性质、法定扣缴义务和税前/税后金额，取得发票不自动免除扣缴。 |
| 廉洁与利益冲突 | 核对合法明示入账、交易相对方人员或受托人利益关系、违法利益输送及解除追偿；沿用依法归责、不为他方违法行为担保代偿的原则。不得用居间费名称掩盖不真实服务或商业贿赂。 |

“以主交易完成为付款前提”、税差补偿、特定票种和税后实收额均须有本单依据；只能作为待确认保护方案，不因本专项命中就直接写入合同。审核报告说明实际缺口，不把发票、税务、廉洁分别重复包装成同一风险。

## 法源与使用边界（2026-11-25）

- [民法典](https://www.cac.gov.cn/2020-06/01/c_15925617772683192.htm)第961—966条：中介报酬与促成合同成立及具体约定有关；主合同全部履行并非统一法定付款条件。
- [反不正当竞争法（2025年修订）](https://www.cnipa.gov.cn/art/2026/5/20/art_104_206437.html)第8条：合法明示佣金与商业贿赂、人员行为归责分别核对。
- [增值税法](https://szs.mof.gov.cn/zhengcefabu/202412/t20241225_3950494.htm)及[实施条例](https://gss.mof.gov.cn/gszhs/falvlagui/202603/t20260313_3985253.htm)：自2026年1月1日起施行，结合实际服务、纳税人和当期政策核验计税及开票，不继续以已废止暂行条例作为现行依据。
- [发票管理办法](https://fgk.chinatax.gov.cn/zcfgk/c100010/c5195084/content.html)：核对开票主体、真实业务与发票要求。
- [个人所得税法](https://www.chinatax.gov.cn/chinatax/n810219/n810744/n3752930/n3752974/c3970366/content.html)第9条及适用扣缴规则：付款人与纳税人的法定义务不能仅以合同内部税费分担约定替代。

上述为核验入口，实际审核仍检查当期有效文本和具体适用条件；不在库内固定居间费税率、佣金比例或补偿金额。
