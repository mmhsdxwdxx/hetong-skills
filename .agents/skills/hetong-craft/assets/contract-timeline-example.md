# 虚构采购情景：履约时间轴

全表金额单位：**万元人民币**。以下全部为虚构演示参数，不是合同范本或任何交易的默认条件。假设含税总价1,000，预付款200；第一批货值600，抵扣全部预付款后实付400；第二批货值400，实付400。示例只约定所列日期，不演示工作日算法。纵向按事件先后排列，行距不代表时间长短。

## 正常交付情景

“情景累计已付”指假设完成本行付款后的累计支出；现实付款情况须另看凭证。本情景未触发待退。资金占用与累计已付可能重合，不相加。
