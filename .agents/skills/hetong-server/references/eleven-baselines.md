# 服务器合同自动审查条款

十一项具体文字版  2026年10月22日

本文件汇集当前确认的十一项服务器合同自动审查内容，供起草、审查与修改时使用。具体金额、比例、台数、甲乙方称谓及正文和附件编号应与实际合同对应；审查删除规则及使用说明分别标示。

# 第一条 预付款保函的开立银行与接受标准

预付款保函由以下十八家全国性银行之一开立：中国工商银行、中国农业银行、中国银行、中国建设银行、交通银行、中国邮政储蓄银行（六大国有商业银行）；中信银行、中国光大银行、华夏银行、中国民生银行、广发银行、兴业银行、平安银行、招商银行、上海浦东发展银行、浙商银行、恒丰银行、渤海银行（十二家全国性股份制商业银行）。

非上述银行开立的保函，甲方有权拒绝接受，且不视为乙方完成保函提供义务。保函文字原则上参照附件7，但因不同银行对于保函出具可能有不同要求，若乙方提供之保函文字未实质性偏离附件7格式，则视为符合本合同要求，甲方不应拒绝。

同时，如果上述银行同意本协议项下的预付款保函可以直接由乙方指定方直接开具给甲方的，甲方同意无条件接受并配合相关手续；甲方认可乙方指定方提供的该种保函视同乙方提供，视为乙方完成保函提供义务；如该情况下保函格式与附件7格式有所区别但内容未实质性偏离的，甲方认可，该保函视同符合本合同要求。

# 第二条 廉洁合作及责任承担

**适用说明：**“本公司”对应我方签约主体，“合作方”对应相对方，落实合同时替换为实际主体称谓。

双方不得实施行贿、索贿、受贿或变相利益输送。合作方及其人员自行实施上述违法行为的，由其依法承担责任，本公司不承担为其违法行为提供担保、补偿或代为清偿的义务。

签署本合同、正常结算或支付合法佣金，不构成本公司对违法行为的授权或认可。

合作方违反本条的，本公司有权解除受影响部分合同而不承担违约责任，并要求合作方赔偿因此造成的损失及合理维权费用。本公司依法应承担的责任除外。

# 第三条 保密违约赔偿及累计上限

**适用说明：**本条为已确认保留的原第9.3条。

任何一方违反本条保密义务的，应赔偿对方因此遭受的可证明的直接损失。无论发生一次或多次违约，违约方因本合同项下保密违约承担的赔偿及合理维权费用，累计不超过本合同含税总价的1%；同一损失不得重复赔偿。因故意、重大过失造成对方财产损失及其他依法不得限制责任的情形除外。

**范围说明：**此前提供的第9.1、9.2条简化稿，以及原第9.4条“永久保密”表述，尚未单独确认为通用固定底线。

# 第四条 总体违约补偿累计上限及履约担保

**适用说明：**以下使用默认3%。具体交易已明确要求5%时，将比例及相应履约担保金额同步调整；“被担保方”替换为实际主体。

除本条规定的例外情形外，任何一方因本合同及其附件项下违约承担的违约金、损害赔偿、资金占用利息及合理维权费用，合并累计不超过本合同含税总价的3%。该上限适用于本合同全部批次及全部违约事项，不因违约次数或保函分批开立而重复计算，亦不因保函减额、到期或注销而改变。上述上限不构成固定赔付金额或最低赔偿承诺。

损害赔偿限于有证据证明、因违约直接造成且订立合同时可以合理预见的实际直接损失，不包括预期利润、商业机会、商誉损失或其他间接损失。同一损失对应的违约金、赔偿金及资金占用利息应相互抵扣，不得重复计算；直接支付或通过保函取得的违约补偿均计入上述累计上限。

被担保方在本合同项下的交付违约补偿义务应纳入履约保函的担保范围，初始履约担保金额应与本合同约定的累计上限相匹配。具体索赔条件、逐台减额及除外事项适用本合同保函特别约定。采用组合保函的，应分别列明履约担保部分与预付款返还担保部分的金额、范围及减额规则。违约补偿不得占用预付款或预付款返还担保额度，亦不得据此扣减应退还的预付款本金。

本合同另有免责或更低专项责任限额约定的，优先适用该约定。保密违约仍适用本合同保密条款，相关赔偿及合理维权费用一并计入上述累计上限，不另行叠加。本合同及其附件中与本条不一致的违约补偿约定，以本条为准。

货款本金的支付及已收款本金的返还不受上述限额限制。造成对方人身损害、因故意或重大过失造成对方财产损失，以及其他依法不得限制责任的情形，不适用本条关于赔偿范围及责任限额的限制。

# 第五条 BIS限制或处罚特别约定

在本合同履行期间，包括乙方已完成部分货物交付后，如美国商务部工业与安全局（BIS）实施或执行出口管制限制、拒绝令、许可证拒绝、暂停或撤销，或其他限制、处罚措施，直接导致剩余全部或部分货物无法合法出口、再出口、转移或交付，且乙方采取合理措施后仍无法排除该交付障碍，乙方有权以书面通知取消受影响未交付部分，自该通知送达甲方时生效，无需另行取得甲方同意。

乙方就该等措施直接导致的不能交付、延期交付及取消，不承担违约金、损害赔偿或资金占用利息，但仍须依第8.4条退还被取消未交付货物对应的全部已收款。

本款系双方就特定履约风险的约定，不以该等措施构成第8.1条所述不可抗力为前提；仅有罚款或处罚而未实际导致上述交付障碍的，不适用本款。

**范围说明：**当前采用上述专项条款。此前将旧版第8.2至8.4条整段设为标准的变更已取消，15日举证等旧版程序要求不作为通用底线；上述退款义务仍保留。

# 第六条 分批交付验收与逐批结算

乙方应自收到甲方预付款之日起，按本合同附件6约定的交货计划向甲方交付货物。甲方同意，本合同货物可以分批交付。

乙方应提前5个工作日向甲方发送到货通知单（附件4）。甲方收到乙方到货通知单后，应当于3个工作日内启动验收测试，安排人员到指定地点完成外包装检查、数量清点及加电测试。验收应于开始验收后72小时内完成；因大批量设备GPU完整压测工作量大，甲方可向乙方发出书面通知，合理顺延完整性能压测完成时间。

该批次货物经压测验收合格后，甲方应及时签署验收确认单（附件2），并于该次压测验收合格后24小时内，按照本合同价款及付款条款约定，向乙方支付该批次应付尾款，同时按本合同约定从已支付的预付款中抵扣该批次对应金额。双方应逐批记录预付款抵扣额、实付尾款及尚未抵扣的预付款余额。具体金额及比例以本合同相关条款约定为准。

本批货物验收合格且对应尾款支付完成后，双方签署货权转移单（附件3）并完成提货。乙方在本批货物验收及尾款支付完成后，再提供下一批次货物，后续批次按照相同流程验收、付款和结算，直至合同约定数量的货物全部交付及全部货款结算完成。

对不符合验收标准的货物，乙方应及时安排调换。甲方延期支付该等未验收合格货物对应的剩余尾款；调换货物验收合格后，甲方支付相应尾款，直至合同约定数量的货物全部交付及全部货款结算完成。

**适用说明：**同步删除其他位置强制“一次性交货”“不得分批”等冲突约定；原示例的台数、预付款比例和尾款比例不固定套用于其他合同。

# 第七条 保函提供期限与未按期开函的处理

乙方在合同生效后20个工作日内提供保函。因不可归责于乙方的事由，导致乙方未能在约定时间内开出保函的，乙方不承担违约责任。

**审查要求：**删除因未开出保函触发合同自动解除、有权解除等约定，正文、生效条款、附件及补充协议一并核对。

# 第八条 验货前资料提供要求的删除

自动识别并删除验货前要求提供、提交、发送、上传或出示PO单、SN码、PI单及同类资料的表述，并同步删除依附于该提前提供义务的前置条件，以及仅因未提前提供而产生的拒绝验货、延期、拒付、违约或解除后果。正文、附件、补充协议及相关引用一并核对。

**适用说明：**本项为审查删除规则。按实际发生阶段识别，验货时核对序列号及验货后资料义务不因关键词相同自动删除。

# 第九条 保函额度拆分逐台减额与索赔范围

**参数说明：**下列比例、金额按具体合同填写。履约比例默认3%，本单明确要求5%时按5%，最高5%；保函总额为本金担保与履约担保之和。每台减额按对应初始担保额度除以合同总台数计算，不固定使用历史金额、比例或台数。

特别说明：本合同附件7保函最高担保金额为人民币【担保总金额】元，由以下两部分构成：合同总金额的【预付款比例】%为甲方预付款本金担保额度，计人民币【本金担保金额】元；合同总金额的【履约比例】%为乙方交付违约补偿的履约担保最高额度，计人民币【履约担保金额】元，不构成固定赔付金额或最低赔偿承诺。

本金担保额度规则：每经甲乙双方共同签署《验收确认单》确认合格交付1台设备，预付款本金担保额度相应扣减其初始额度除以本合同设备总台数的金额；完成全部设备合格交付的，本金担保额度扣减归零。

履约担保规则：履约担保最高额度按照交付台数相应扣减。实际履约索赔以适用本合同约定宽限期后乙方仍应承担而未支付的交付违约补偿为限。保函赔付金额为已到期未返还的应退预付款本金与按本合同尚未支付的未交付违约补偿之和，分别不得超过对应剩余担保额度，合计不超过保函剩余最高担保金额。

货物质量瑕疵、发票违约、售后服务及质保纠纷，均不属于本保函赔付触发情形，甲方就该部分损失通过协商、诉讼途径向乙方另行主张。该等另行主张的违约补偿仍适用本合同总体违约补偿累计上限及更低专项限额；本合同另有免责约定的，适用该约定。

已实际退还的预付款本金及银行就同一本金已支付的金额应相应扣减本金担保额度；双方应及时配合办理已交付、退款及赔付对应的保函减额。银行付款不当然确定甲乙双方最终责任，甲方取得超过本合同约定应得款项或重复受偿的，应返还超收部分。

本款不改变银行依保函承担的独立付款义务，担保范围、减额及索赔声明应同步载入附件7及实际保函。

**核对要求：**对应原文第7.8条宽限期、第7.11条累计上限及附件7，落实到实际编号。保函减额不改变合同累计责任上限；未提供实际保函时，其内容标记为待核实。

# 第十条 发票信息不符的赔偿责任

**插入位置：**乙方开具发票的相关约定之后。

因发票上的产品名称和规格型号等信息与本合同项下实际交易货物的相关信息存在不符的法律后果及税金损失等，乙方不承担赔偿责任。

**核对要求：**同步处理其他发票赔偿及税金损失承担条款的冲突，保留原文针对特定信息不符事项的赔偿责任范围。

# 第十一条 保函生效与失效时间

保函自乙方收到全部预付款之日起生效，并于最后一批货物交付后30个自然日内失效。

**核对要求：**正文、附件及实际保函同步；保函提供期限仍按第七条执行。
